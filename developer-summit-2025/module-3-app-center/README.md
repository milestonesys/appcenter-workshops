# Module 3: Exploring App Center

**Duration:** 10 minutes

Welcome to Module 3! Now that your development environment is set up, let's dive deep into App Center - the centralized marketplace and management hub for XProtect applications.

## 🎯 Learning Objectives

By the end of this module, you will:
- ✅ Navigate the App Center interface confidently
- ✅ Understand the application marketplace structure
- ✅ Know how to install and manage applications
- ✅ Understand app permissions and security models
- ✅ Be familiar with the publishing workflow for developers

## 📋 Prerequisites

- Module 1 and 2 completed successfully
- App Builder CLI working
- App Center installed and accessible
- XProtect VMS connection established
- At least one sample application installed

## 🚀 Step-by-Step Instructions

### Step 1: App Center Interface Tour (3 minutes)

1. **Access App Center:**
   - Open your web browser
   - Navigate to App Center: `http://<cluster-ip>/app-center`
   - Log in with your XProtect credentials

2. **Explore the Main Dashboard:**
   - **Find new apps:** Browse marketplace applications
   - **Installed apps:** View currently installed applications
     - View details of installed apps, including monitoring details and logs
   - **System:** Check Runtime Platform health and settings

### Step 2: Browse the Application Marketplace (3 minutes)

1. **Marketplace Overview:**
   - Navigate to "Find new apps" section
   - Observe different application categories:
     - **System**: System Components
     - **Video OS**: Milestone Apps
     - **Partner**: Partner Applications
     - **Sandbox**: This is where your development apps will appear

   **Note:**: These categories/filters might be subject to change.

2. **Application Details:**
   - Click on various applications to view:
     - Application descriptions
     - Required permissions
     - System requirements
     - Installation requirements

3. **Filtering and Search:**
   - Use category filters to narrow down applications

### Step 3: Install and Manage Applications (4 minutes)

1. **Install a New Application:**
   - You already installed an app in Module 1.

2. **Application Monitoring:**
   - View metrics and logs for the installed application.
     - Naviagate to the app under "Installed apps".
     - Look at data available under the different tabs.
  
3. **Application Management:**
   - Try uninstalling the app you installed in Module 1.
     - Navigate to the app under "Installed apps".
     - Press the "Uninstall" button and confirm the action.

## 🔍 Verification Checklist

Before proceeding to Module 3, ensure you have:

- [ ] Successfully navigated all App Center interface sections
- [ ] Installed at least 1 applications from the marketplace
- [ ] Uninstalled an application successfully
- [ ] Reviewed application logs and monitoring data

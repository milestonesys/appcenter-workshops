# Developer Summit 2026 - Build a Milestone MFE with AI Tooling

In this hands-on workshop you'll use an AI agent to build a micro frontend (MFE) for the XProtect App Platform, deploy it, and see it running in XProtect Smart Client.

## 🎯 What You'll Build

A **System Health dashboard** for XProtect operators: is the system running properly, and are any cameras, devices or servers offline?

You build on your own laptop. We provide a shared App Platform, XProtect and (if you need one) a Smart Client VM.

> ⚠️ The App Platform is **shared by everyone in the room**, so your app needs a unique name. You'll pick one in Module 1.

## 📋 Before You Start

- Complete **[PREREQUISITES.md](./PREREQUISITES.md)** before the workshop
- Grab a **credentials handout** from an instructor
